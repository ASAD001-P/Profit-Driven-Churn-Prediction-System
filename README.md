# Profit-Driven Churn Prediction System

A machine learning project that approaches customer churn prediction from a profit-oriented perspective, combining churn prediction with Customer Lifetime Value analysis.

## Features

* Customer churn prediction
* Quad-model ensemble
* Customer Lifetime Value (CLV) analysis
* SHAP-based model interpretability
* Profit-oriented retention analysis

## Technologies

* Python
* Jupyter Notebook
* Machine Learning
* SHAP
* Data Analysis

## Getting Started

Clone the repository:

```bash
git clone https://github.com/ASAD001-P/Profit-Driven-Churn-Prediction-System.git
```

Open `Data_Mining_Project.ipynb` in Jupyter Notebook or Google Colab and run the notebook cells.

## Purpose

This project demonstrates how churn prediction can be combined with customer value and model interpretability to support more effective, data-driven retention decisions.
